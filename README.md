# JARVIS

Asistente personal de escritorio para Windows.

## Descargar

- **Windows:** [Instalar JARVIS.exe](https://github.com/ggalvezztgc/Jarvis/releases/latest/download/Instalar.JARVIS.exe)
- **Mac:** [JARVIS para Mac.zip](https://github.com/ggalvezztgc/Jarvis/releases/latest/download/JARVIS.para.Mac.zip)

Estos dos enlaces llevan siempre a la **última versión**. Todas las versiones, con sus notas, están en [Releases](https://github.com/ggalvezztgc/Jarvis/releases).

Si Windows avisa de «editor desconocido» al abrir el instalador, pulse «Más información» y después «Ejecutar de todas formas».

## Actualizar

El instalador solo hace falta la primera vez. JARVIS comprueba solo si hay una versión nueva (al arrancar y cada 12 horas) y la instala desde **Ajustes → Sistema → Versión y actualizaciones**, o diciéndole «actualízate».
